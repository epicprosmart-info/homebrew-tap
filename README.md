# homebrew-tap

Homebrew formulae for CoSec Shield tools. Generated by the release process of
[epicprosmart-info/cosec-cli](https://github.com/epicprosmart-info/cosec-cli) — do not edit by hand.

```sh
brew install epicprosmart-info/tap/cosec-cli     # current: v1.0.0-rc.3
brew upgrade cosec-cli
```

The formula installs the signed, checksummed binary of the matching GitHub release (sha256 per CPU).
Verification, license and security contact: https://github.com/epicprosmart-info/cosec-cli
